# Rehab Candidate Review

A mobile-first educational questionnaire for organizing possible inpatient rehabilitation referrals.

## Current status

This is an early, unvalidated prototype. It organizes supporting factors, concerns, missing information, follow-up questions, medical or functional barriers, and facility-capability issues.

The questionnaire now includes cardiac tolerance, oxygen requirements, IV infusions, diabetes management, WBC status, kidney function, dialysis scheduling, cancer treatment, therapy tolerance, maximum-assistance progress, cognition, and discharge support.

Some thresholds reflect one facility’s operational capabilities and are not universal admission, Medicare, payer, regulatory, or medical standards.

The app does not make admission, denial, treatment, coverage, or medical-necessity decisions.

## Privacy

Do not enter identifying patient information. Use only generic labels such as `Patient 1`.

## Run locally

Run `python3 -m http.server 8000`, then open `http://localhost:8000`.

See `DISCLAIMER.md` for limitations.
